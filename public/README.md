# Rubenium

A glowing ball for Windows 10 / 11 that opens into a gamer command centre: music for any app with lyrics,
crosshair, screen colours, stats, timer, app launcher, themes, and an online side with mini games and a casino
simulation played with free virtual coins.

**Download:** [RubeniumSetup.exe (latest)](https://github.com/REMMETT-py/rubenium-releases/releases/latest/download/RubeniumSetup.exe)

It installs for your Windows account only (no admin rights) and can be removed from Settings → Apps. Every
download has a `.sha256` file next to it; Rubenium checks it before installing an update.
