Rubenium 1.0

Download RubeniumSetup.exe below. It installs Rubenium for your Windows account (no admin rights needed), adds it to the Start menu, and it can be removed from Settings > Apps. Updates then install by themselves.

- Install and updates: Rubenium installs like a normal Windows app, and the Update button installs new versions in the background.
- Sound: soft, very quiet sounds when you switch something on or off (can be turned off in Settings > Audio).
- Stats: Top apps measured like Task Manager, with bars on a fixed scale. Much lighter on the PC.
- RL Swap: pictures for every swap, Black Lunation ready, clearer outlines for pending changes.
- Themes: 15 themes, plus styles for the R and the song ring that unlock with time.
- Rubenium uses much less processor.
